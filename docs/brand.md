# Brand

The brand kit and clickable prototype live in the WORKLINK project on Claude.

| Token | Hex | Use |
| --- | --- | --- |
| Navy 900 | `#0B1F3A` | Header, hero, primary text on light |
| Navy 950 | `#071427` | Footer |
| Teal 700 | `#0A7C78` | Buttons, links on light backgrounds |
| Teal 400 | `#2BB5AE` | Accents on navy |
| Amber 700 | `#B45309` | Closing-soon deadlines only |
| Paper | `#F6F8FB` | Page background |

Fonts: **Bricolage Grotesque** (headings), **Figtree** (body), both from Google Fonts via `next/font`.
Tokens are defined in `apps/web/src/app/globals.css` (`@theme`). Tagline: *Opportunities. Employment. Growth.*
